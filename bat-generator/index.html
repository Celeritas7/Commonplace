Running the file

  • Save the .bat where the script expects it. Most types use the folder the file sits in (%~dp0).
  • Double-click to run. While testing, open cmd in that folder and type the file name, so the window stays open and errors stay visible.
  • If Windows warns that the file came from the internet: right-click → Properties → Unblock.

Handled for you

  • Windows line endings (CRLF) in every download.
  • Escaping of text you type: % → %%, and ^ & | < > ( ) get a ^ in messages.
  • Quoted paths, so folders with spaces work.

Before you trust it

  • Read the explained lines once, so you know what the script will do.
  • Test delete, move and mirror scripts on a copy of the folder first.
  • Test git scripts in a throwaway repository.
