Prepare this iPad

  1. Connect to Wi-Fi. Open the C/C++ home page in Safari and sign in.
  2. For an installed app: Share → Add to Home Screen → keep Open as Web App on if offered. Open that new icon and sign in there.
  3. In the browser or installed app you will actually use, tap Study offline and download this pack. Safari and Home Screen apps can have separate storage; prepare each separately.
  4. Wait for Ready offline. Open Practice Lab online and use Save problems offline if you want your account problem list too. Those records are separate from the lesson pack.
  5. Switch Wi-Fi off, close and reopen the app, open a lesson, and write a code draft. Reopen it to check the draft. Run will explain that compilation needs internet.

Your work stays on this device

Updates and repairs do not clear local practice, drafts, bookmarks, highlights, notes, or downloaded packs. The existing backup menu remains available. Do not clear website data to fix downloads: that removes local work too. Safari may reclaim storage; check readiness before leaving Wi-Fi and export important work.

Code drafts, saved problem snapshots and local notes are device-only; this change does not add cloud synchronization for them. Existing reading-progress synchronization is separate and needs internet/sign-in; its live account behavior has not been verified here. Cloud attempts, grading, the cloud mistake bank, account problem refresh and external links require internet. No offline compilation/attempt queue is added.

Browser-based Clang/WebAssembly compilation is technically possible, but requires a compiler, linker, C++ libraries and a compatible runtime. This release does not include one or claim it works on a physical iPad.
