What works offline?

Reading, local quizzes, SQLite queries and local exercise grading work without a server. SQLite is real SQL execution, but PostgreSQL-only examples and instructions that ask for pgAdmin/Python need those external tools.

Database changes: sample tables live in memory. INSERT, UPDATE and CREATE affect the current lab session; reload or Reset data restores the sample tables. Database changes are not saved or synchronized. Home and free-lab query drafts are now saved locally; module and exercise answers retain their existing local storage.

Your study records: updates and repair never clear localStorage or IndexedDB, including existing practice, bookmarks, highlights and notes. Downloads contain app files, not a backup of personal records.

Online-only: new sign-ins, cloud access and external SQLZoo links require internet. The local practice page is included. Existing code attempts to synchronize module completion, checks and the Mistake Bank after a signed-in page load. Cloud synchronization was not verified against your account; do not rely on it as a backup. SQLZoo offline solves, draft queries, bookmarks and notes are not promised to sync later.

Setup stuck or an older version?

Reconnect and use Repair. It refreshes only SQL’s worker and temporary page cache. Downloaded packs and saved study records are kept; other Commonplace sections are untouched.
