Add Web Studio to your iPad Home Screen

  1. In Safari, tap Share → Add to Home Screen. If needed, tap More to find it. Keep Open as Web App on if shown, then tap Add.
  2. While connected, open the Web Studio icon and sign in if asked. Choose Study offline and download or resume the pack there. Safari and the Home Screen app can have separate downloads.
  3. When it says Saved files verified, close Web Studio, turn Wi-Fi off and tap its icon again. Open Practice and run a preview.

Your lessons are stored inside the app. The Home Screen icon is what you tap to launch them.
