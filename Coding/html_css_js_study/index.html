iPad setup and what works offline
  1. Open Web Studio in a regular Safari tab while connected. For a Home Screen app, use Share → Add to Home Screen, then open its icon.
  2. Sign in and download inside the browser or installed app where you will study. Safari and the Home Screen app may have separate saved data.
  3. Wait for Saved files verified. Close Web Studio, turn Wi-Fi off and reopen it, then run a preview. Keep your account signed in for offline access.

Included: reading, quizzes, real code previews and exercise checks, projects, embedded images, notes, bookmarks and backups. External scripts, remote images and web services are blocked in the practice preview; use embedded images for offline projects.

      SAMPLE LEARNING BOOK
      Build one small webpage.
      Three short lessons to review the app: give a reading card its structure, style it, then make its button count.
      Start with HTML, then CSS, then JavaScript. Each lesson has eight reading parts, editable practice, a prediction and one five-question check. Your saved place and edits stay when switching lessons.
      A quick way to review the app
      1. Open HTML and read the walk-through. Bookmark a part and add a note in My notes.
      2. Open practice, change the heading and run the preview. Return to the lesson.
      3. Finish Before you go: answer the check and mark the lesson read.
      4. Continue with CSS spacing, then JavaScript: add two per click and check for Clicks: 4 after two clicks.
      5. Reload while connected and check that your note, edits and reading mark remain.
      These samples run without external services. Use Study offline to download and verify all required files before disconnecting.
