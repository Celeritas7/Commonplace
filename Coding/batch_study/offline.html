What works offline?

Lessons, saved notes, bookmarks, highlights, text checks and the sandbox work locally. The sandbox simulates a limited set of commands. It does not execute Windows batch files. Run downloaded .bat files only on a Windows computer.

Sign-in, cloud progress, external links and other Commonplace sections require internet or their own downloads. Sign in and open a lesson in this browser before leaving Wi-Fi.

Practice, annotations and notes remain in this browser’s local storage. Existing lesson completion sync attempts to reconcile completed items when signed in and the lesson is reopened online. This is not a verified backup of all edits: do not assume notes, highlights, scripts or undone progress synchronize. Use the existing export controls for backups.

On iPad

  1. Open BAT in Safari while connected. Sign in and open a lesson.
  2. For a Home Screen app: Safari → Share → Add to Home Screen. Open that app while still connected and sign in there if needed.
  3. In the browser or Home Screen app where you will study, open Study offline, download and wait for Ready offline.
  4. Turn off Wi-Fi and mobile data, close and reopen that same app. Open the sandbox and try echo hello.

Safari and Home Screen storage may differ. Prepare and test each separately. Avoid private browsing. iPadOS can reclaim website storage; check downloads before travelling. Clearing website data removes saved work and downloads.

Repair without deleting work

Refresh only BAT’s worker, setup page and download list. Saved packs, local practice, annotations and other sections are kept. Reconnect first.
