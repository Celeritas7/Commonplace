01

The Briefing

read this first

Welcome to batch scripting. This is where your automation journey begins.

A batch file is just a text file with a .bat extension. Inside it, you write commands that Windows runs one by one — like a to-do list for your computer.

The four commands in every single batch file

@ECHO OFF—Always the first line. Without it, Windows would show every command before running it, making the output messy. Think of it like telling a chef: “Just bring me the food, don't read the recipe out loud while cooking.”
ECHO—Prints text to the screen. Whatever you write after ECHO appears in the terminal window.ECHO HELLO WORLD  → shows "HELLO WORLD" on screen
PAUSE—Stops the script and shows “Press any key to continue.” Without this, the terminal window would flash open and close instantly — too fast to read anything.
REM—Short for “remark.” These are comments — notes for humans. The computer ignores them completely. Your lecturer used these to explain what each section does.

The file operation commands

CD—Change Directory. Moves you to a different folder, like double-clicking a folder in File Explorer.CD C:\Users\Desktop\Projects  → takes you there
CD  (alone, no path)  → shows where you currently are
CLS—Clears the screen. Wipes everything visible in the terminal window. Fresh start.
COPY—Copies a file from one place to another. The original stays where it is.COPY source.txt C:\Backup\  → makes a copy in Backup
COPY *.txt C:\Backup\  → copies ALL .txt files (* means "everything")
COPY "my file.txt" C:\Backup\  → names with spaces need quotes
DEL—Deletes files. Be careful — this does not go to the Recycle Bin.DEL file.txt  → deletes that one file
DEL /s *.txt  → deletes all .txt files including in subfolders
DEL /p *.txt  → asks permission before each delete. Much safer.
MOVE—Like COPY but removes the original. Cut and paste, not copy and paste.MOVE file.txt C:\NewFolder\  → moves the file
MOVE C:\OldFolder C:\NewFolder  → moves an entire folderIf the destination folder does not exist, Windows creates it automatically.
ATTRIB—Changes file properties (attributes). Every file has hidden flags:+r = make read-only (cannot edit)  ·  -r = remove read-only
+h = make hidden  ·  -h = unhide
+a = mark as "needs backup" (archive)You can combine them: ATTRIB -h +r file.txt unhides and makes read-only.
FIND—Searches for text inside a file.FIND "hello" myfile.txt  → shows the lines containing "hello"
REN—Renames a file.REN "oldname.txt" "newname.txt"Note: you only write the new filename, not the full path.
Why this matters for you

Your Python automation scripts (image converter, PDF maker) use these exact same concepts — they copy files, move them, check if they exist. Understanding these bat commands helps you understand what your Python scripts do at the operating system level.

Forget computers for a moment. Imagine you are organizing a physical office.

ECHO=Speaking out loud. “The report is ready!” You are announcing something.
@ECHO OFF=Telling your assistant: “Just do the tasks silently, don't narrate every step.”
PAUSE=Stopping to wait. “Hold on, let me check before you continue.”
REM=A sticky note on your desk. Reminds you what to do, but your assistant ignores it.
CD=Walking to a different room. CD C:\Users\Desktop means “Go to the Desktop room.”
COPY=Photocopying a document. Original stays, you get a duplicate somewhere else.
MOVE=Physically carrying a document to another room. It is no longer where it was.
DEL=Shredding a document. Gone forever (no recycle bin!). The /p flag is like having someone ask “Are you sure?” before each shred.
ATTRIB=Putting labels on a folder. “Read only” means nobody can edit it. “Hidden” means it is tucked away in a drawer.
FIND=Searching through a stack of papers for a specific word.
REN=Peeling off the old label and sticking a new name on the folder.
The point

The beauty of batch files is that you write these instructions once, and the computer does them instantly — even if it is 10,000 files.

02

The Walkthrough

8 steps · mark each done
STEP 01

Your First Batch File Line

Every batch file starts with @ECHO OFF. This hides the commands themselves from printing on screen — you only see the output. The @ symbol hides even this line itself.

@ECHO OFF
STEP 02

Printing and Comments

ECHO prints text to the screen — anything you write after it appears exactly as typed. REM creates a comment; the computer ignores everything after it. Use comments to explain your code.

ECHO HELLO WORLD!!
REM This is a comment - totally ignored
STEP 03

Navigation and Control

CD changes your current directory (folder). Used alone, it shows where you are. cls clears the screen. PAUSE stops and waits for a keypress — keeps the window open so you can read output.

CD C:\Users\VaishM\Desktop\ac
CD
cls
PAUSE
STEP 04

Copying Files

COPY source destination copies files. Use * as a wildcard (e.g. *.txt = all text files). When paths have spaces, wrap them in "quotes" or Windows breaks the command.

COPY "path\*.txt" destination
STEP 05

Deleting Files Safely

DEL removes files. The /s flag searches subfolders. The /p flag asks for confirmation before each delete — combine them for safe bulk deletion.

DEL /p /s "path\*.txt"
STEP 06

Moving and Renaming

MOVE source destination moves files (originals disappear, unlike COPY). Without a destination, it renames in place. You can move entire folders — if the destination doesn't exist, Windows creates it.

MOVE B CDE
STEP 07

File Attributes

ATTRIB changes file properties. +r makes read-only, +h hides the file, -r or -h removes them. Combine multiple: ATTRIB -h +r "file" unhides and protects in one command.

ATTRIB +r "filepath"
ATTRIB -h +r "filepath"
STEP 08

Searching and Renaming

FIND "text" "filepath" searches inside a file and prints matching lines — both arguments need quotes. REN "full\path\old.txt" "new.txt" renames: the first argument is the full path, the second is only the new name (no path).

FIND "MAYANK" "filepath"
REN "full\path\oldname.txt" "newname.txt"

Practice

6 challenges · answers shown
01Predict the output◆

What will this script show on screen?

@ECHO OFF
ECHO Hello
ECHO World
PAUSE
Answer
Hello
World
Press any key to continue...
ECHO prints each text on a new line. @ECHO OFF hides the commands themselves. PAUSE shows “Press any key to continue...” So you see three lines of output.
How did you do?
02Multiple choice◆

What does the * symbol mean in: COPY "C:\Folder\*.txt" D:\Backup\

The asterisk (*) is a wildcard that means “anything.” So *.txt means “any filename that ends with .txt.” This is one of the most powerful features in batch scripting.
03Multiple choice◆

What is the difference between COPY and MOVE?

COPY = photocopy (original stays). MOVE = physically carry it (original is gone). Think of it like copy-paste vs cut-paste.
04Modify the code◆◆

Your lecturer's 13_DELETE.bat uses DEL /p /s to delete .txt files with confirmation. How would you modify it to delete all file types (not just .txt) but only in the main folder (not subfolders)?

DEL /p /s "C:\Users\Desktop\DELETE\*.txt"
Answer
DEL /p "C:\Users\Desktop\DELETE\*.*"
Two changes: (1) Remove /s so it does not search subfolders. (2) Change *.txt to *.* which means “all files regardless of extension.” The /p stays so you still get confirmation for safety.
How did you do?
05Predict the output◆

What does CD do when used without any path after it?

@ECHO OFF
CD
PAUSE
Answer
It prints the current directory path
(e.g. C:\Users\YourName)
CD alone is like asking “where am I?” It displays your current working directory. This is useful for debugging — to verify you are in the right folder before running file operations.
How did you do?
06Write the script◆◆

Write a batch script that: (1) clears the screen, (2) prints “Organizing files...”, (3) copies all .pdf files from Desktop\Inbox to Desktop\Archive, (4) prints “Done!” and waits.

Answer
@ECHO OFF
CLS
ECHO Organizing files...
COPY "C:\Users\YourName\Desktop\Inbox\*.pdf" "C:\Users\YourName\Desktop\Archive"
ECHO Done!
PAUSE
This combines 5 commands you learned: @ECHO OFF (clean output), CLS (fresh screen), ECHO (status messages), COPY with a wildcard (bulk file operation), and PAUSE (keep the window open). This is essentially a simplified version of your real file automation.
How did you do?
05

The Test

5 challenges · no hints
01Multiple choice◆

Why do we put @ECHO OFF as the first line of almost every batch file?

Without @ECHO OFF, every command would be printed to the screen before its result. So instead of just seeing “Hello World”, you would see “ECHO Hello World” followed by “Hello World.” The @ symbol also hides the ECHO OFF command itself.
02Multiple choice◆

What does DEL /s do differently from plain DEL?

/s stands for “subdirectories.” Without it, DEL only looks at the one folder you specified. With /s, it searches every folder inside that folder, and their folders, and so on. Very powerful — and dangerous without /p.
03Predict the output◆◆

What happens when you run this command?

ATTRIB +h +r "C:\secret.txt"
Answer
The file becomes both hidden AND read-only
+h makes the file hidden (invisible in File Explorer). +r makes it read-only (cannot be edited or deleted normally). You can combine multiple attribute changes in one command. To reverse it: ATTRIB -h -r "C:\secret.txt"
How did you do?
04Multiple choice◆

Why do filenames with spaces need to be wrapped in quotes?

The command COPY My File.txt D:\Backup would confuse Windows — it thinks “My” is the source, “File.txt” is the destination, and “D:\Backup” is an error. Quotes tell Windows: everything inside these quotes is ONE path.
05Write the command◆◆

Write the ATTRIB command to make a file visible (unhide it) but keep it read-only. The file is currently hidden and read-only — ATTRIB shows: H R C:\myfile.txt

Answer
ATTRIB -h +r "C:\myfile.txt"
Use -h to remove hidden, and +r to keep (or add) read-only. The minus removes, the plus adds. You can do both in one command. If read-only is already set, +r just keeps it — no harm done.
How did you do?
