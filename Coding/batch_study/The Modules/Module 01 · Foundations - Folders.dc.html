Q01 PREDICT THE OUTPUT ◆

What will this script show on screen?

@ECHO OFF
ECHO Hello
ECHO World
PAUSE
SET /P ANSWER=
:: ANSWER
Hello
World
Press any key to continue...
ECHO prints each text on a new line. @ECHO OFF hides the commands themselves. PAUSE shows “Press any key to continue...” So you see three lines of output.

Q02 MULTIPLE CHOICE ◆

What does * mean in: COPY "C:\Folder\*.txt" D:\Backup\

The asterisk (*) is a wildcard that means “anything.” So *.txt means “any filename that ends with .txt.” This is one of the most powerful features in batch scripting.
Q03 MULTIPLE CHOICE ◆

What is the difference between COPY and MOVE?

COPY = photocopy (original stays). MOVE = physically carry it (original is gone). Think of it like copy-paste vs cut-paste.
Q04 MODIFY THE CODE ◆◆

Your lecturer's 13_DELETE.bat uses DEL /p /s to delete .txt files with confirmation. How would you modify it to delete all file types (not just .txt) but only in the main folder (not subfolders)?

DEL /p /s "C:\Users\Desktop\DELETE\*.txt"
SET /P ANSWER=
:: ANSWER
DEL /p "C:\Users\Desktop\DELETE\*.*"
Two changes: (1) Remove /s so it does not search subfolders. (2) Change *.txt to *.* which means “all files regardless of extension.” The /p stays so you still get confirmation for safety.

Q06 WRITE THE SCRIPT ◆◆

Write a batch script that: (1) clears the screen, (2) prints “Organizing files...”, (3) copies all .pdf files from Desktop\Inbox to Desktop\Archive, (4) prints “Done!” and waits.

COPY CON myscript.bat
:: ANSWER
@ECHO OFF
CLS
ECHO Organizing files...
COPY "C:\Users\YourName\Desktop\Inbox\*.pdf" "C:\Users\YourName\Desktop\Archive"
ECHO Done!
PAUSE
This combines 5 commands you learned: @ECHO OFF (clean output), CLS (fresh screen), ECHO (status messages), COPY with a wildcard (bulk file operation), and PAUSE (keep the window open). This is essentially a simplified version of your real file automation.

T01 MULTIPLE CHOICE ◆

Why do we put @ECHO OFF as the first line of almost every batch file?

Without @ECHO OFF, every command would be printed to the screen before its result. So instead of just seeing “Hello World”, you would see “ECHO Hello World” followed by “Hello World.” The @ symbol also hides the ECHO OFF command itself.
T02 MULTIPLE CHOICE ◆

What does DEL /s do differently from plain DEL?

/s stands for “subdirectories.” Without it, DEL only looks at the one folder you specified. With /s, it searches every folder inside that folder, and their folders, and so on. Very powerful — and dangerous without /p.
T03 PREDICT THE OUTPUT ◆◆

What happens when you run this command?

ATTRIB +h +r "C:\secret.txt"
SET /P ANSWER=
:: ANSWER
The file becomes both hidden AND read-only
+h makes the file hidden (invisible in File Explorer). +r makes it read-only (cannot be edited or deleted normally). You can combine multiple attribute changes in one command. To reverse it: ATTRIB -h -r "C:\secret.txt"

T04 MULTIPLE CHOICE ◆

Why do filenames with spaces need to be wrapped in quotes?

The command COPY My File.txt D:\Backup would confuse Windows — it thinks “My” is the source, “File.txt” is the destination, and “D:\Backup” is an error. Quotes tell Windows: everything inside these quotes is ONE path.
T05 WRITE THE COMMAND ◆◆

Write the ATTRIB command to make a file visible (unhide it) but keep it read-only. The file is currently hidden and read-only — ATTRIB shows: H R C:\myfile.txt

SET /P ANSWER=
:: ANSWER
ATTRIB -h +r "C:\myfile.txt"
Use -h to remove hidden, and +r to keep (or add) read-only. The minus removes, the plus adds. You can do both in one command. If read-only is already set, +r just keeps it — no harm done.
