REM :: HOW TO READ A SYNTAX LINE

Words in capitals are the command. Anything after it is what you hand it — a file, a folder, a number. A slash starts a switch (/S, /Q) that changes how the command behaves. Square brackets in Windows' own help mean optional; this list writes real examples instead, so you can copy a line and change the names.
