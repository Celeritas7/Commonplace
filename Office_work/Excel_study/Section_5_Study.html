Make a decision with IF

Check whether a batch meets its target. Let a formula return Ready or Review whenever the underlying values change.

One condition, two possible results

IF has three parts: a logical test, the value returned when the test is true, and the value returned when it is false.

=IF(condition,"text if true","text if false")

Use >= to include equality. A batch of exactly five items meets a minimum of five; a batch of four does not.

In desktop Excel, enter the formula in a cell, press Enter, and change the input values to see the result recalculate. This practice checks formulas when you choose Preview or Submit.
