Study the concept

Each row is one item. Its ID, description, status, quantity, price, discount and date belong together. Keep the headers outside the data rows.

Scroll the worksheet sideways to see every column on a narrow screen. The displayed row numbers keep gaps when a filter hides records.

Number formats

Formatting keeps the stored value. For example, 0.025 becomes 2.5% on screen. Choosing PHP instead of JPY changes the label, not the exchange value.
Create a table
This practice uses the complete A1:G7 range and its existing headers. In Excel, select the range, then Home → Format as Table.
Sort whole records
All seven fields move together, including hidden records. Numbers sort by value, so 2 comes before 10 and 100. Blank quantities stay last. Sort again after editing a sort value.
Filter records
Both conditions apply together. This practice matches status labels exactly. Hidden rows remain in the worksheet. After editing, reapply the current filter to update which records are shown. Clearing filters shows every record in its current order.
Set entry rules

The enabled rules reject invalid direct entries, including blanks. Use the listed status spelling in this practice. Applying a rule keeps existing values; check them separately. In Excel, copy/paste or deletion can bypass validation alerts, so also use Data → Data Validation → Circle Invalid Data.
Try an input change
Choose the item by its ID, even after sorting or filtering. An unsuccessful edit keeps the worksheet value and your typed draft. Independent tasks require the original values; use Reset worksheet after experimenting.
