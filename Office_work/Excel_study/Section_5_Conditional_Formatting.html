Spot low values with conditional formatting

Set a rule to automatically draw attention to values that need review, without changing the numbers in the worksheet.

A rule changes appearance, not data

A conditional format applies only when its condition is true. For a Less Than 5 rule, a cell containing 4 is highlighted, but cells containing 5 or 6 are not. Editing 6 to 3 makes the format appear automatically.

In Microsoft Excel: select the cells, then choose Home → Conditional Formatting → Highlight Cells Rules → Less Than. Enter the threshold and choose a format. Use Manage Rules to inspect the applied range or Clear Rules to remove formatting.

Unlike IF, conditional formatting does not create a new result value or formula in another cell.

Edit a conditional-formatting rule

This practice supports one cell-value rule, a contiguous range within B2:B4, five numeric comparisons and three formats. Blank or invalid worksheet values are marked for review and are not highlighted. General formulas, multiple rules and priority are outside this practice.
