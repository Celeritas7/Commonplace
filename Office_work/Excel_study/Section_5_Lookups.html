Find a price by its item code

Connect an item code to the corresponding amount in a small catalog. Practise exact XLOOKUP and VLOOKUP before using them in quotations, inventory and expense sheets.

One key, a matching row, and a returned value

XLOOKUP: specify a key, search range and return range. Exact matching is the default. XLOOKUP is available in newer Excel versions, including Microsoft 365 and Excel 2021 or later.

VLOOKUP: specify the key, a table range, a column number and FALSE for an exact match. The first column contains the keys. Column 3 means the third column of that table, not necessarily worksheet column C.

Exact matching does not require a sorted catalog. If a code is missing, the result is #N/A; it is not zero. A duplicate code returns the first match in this practice, so use unique item codes in business catalogs.

Lookup cells

Practice subset: fixed A2:C4 catalog, ASCII codes of 1–24 characters starting with a letter, letters/digits/hyphens/underscores only, case-insensitive exact matching. XLOOKUP uses default exact or omitted fallback and match mode 0; VLOOKUP requires FALSE or 0. No wildcards, approximate matching, custom fallback, nesting or formula copying. Numeric amount cells must contain valid numbers.
