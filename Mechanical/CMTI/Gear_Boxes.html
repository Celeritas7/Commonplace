Speed series & progression ratio φ p.599–603

Spindle speeds are stepped in geometric progression — each speed φ times the last — so the relative speed loss when dropping to the next step is constant across the range.

nz = n1·φz−1    Rn = nmax/nmin = φz−1    z = 1 + log Rn / log φ z = number of speeds, Rn = speed range.

Loss = (φ − 1)/φ — the productivity sacrificed when the ideal speed falls between two steps.

Structure formula p.604–609

A gearbox giving z speeds is built from transmission groups in series: z = p₁·p₂·p₃… where p is the number of ratios in each group. Each group has a characteristic x — the step (in units of log φ) between its rays:

z = p₁(x₁) · p₂(x₂) · p₃(x₃)    x₁ = 1,  x₂ = p₁,  x₃ = p₁·p₂ for the normal (fanning-out) structure. Example: 12 = 3(1)·2(3)·2(6).

Ray (speed) diagram p.610–614

The ray diagram plots shafts as vertical lines and speeds as horizontal levels spaced log φ apart; each transmission is a ray whose slope is its ratio: i = φk spans k intervals. Drawing rules:

  • Start from the spindle line and work back to the motor.
  • Keep rays as flat as possible — steep reductions mean large gear pairs.
  • Put the largest reductions in the last group (slowest shaft, fewest revolutions → least wear and noise).

Transmission limits p.615–619

1/4 ≤ i ≤ 2    r = imax / imin ≤ 8  per group i = single-pair ratio (speed boxes). Reductions below 1/4 give oversized wheels; step-ups above 2 run noisily. r ≤ 8 caps the characteristic: φx(p−1) ≤ 8.
Check

With φ = 1.41: 8 = 1.41⁶, so x(p−1) ≤ 6 — the variant 2(1)·2(2)·3(4) has x(p−1) = 8 in its last group and is inadmissible; 3(1)·2(3)·2(6) just passes.
