Standard spur gearing p.258–259

For standard (uncorrected) involute gearing the basic-rack axis — the line where tooth thickness equals gap — is tangent to the pitch circle. All dimensions follow from the module m and tooth count z (20° full-depth):

Corrected (profile-shifted) spur gearing p.260–268

It is often advantageous to correct a gear by shifting the cutter profile by an amount m·x. The tooth stays a part of the same involute on the same base circle, but a different portion of the involute becomes the active flank.

  • Positive correction (cutter shifted away from the gear axis) — strengthens the tooth root, avoids undercut on small pinions, raises the practical minimum tooth count.
  • Negative correction (cutter shifted toward the axis) — used on the larger wheel to keep a chosen centre distance.

Correction needs no special tooling — it's achieved with normal machines by adjusting cutter depth. The undercut limit for a standard 20° rack is zmin ≈ 17 teeth; positive shift lets you go below that.

Strength calculation p.270–274

A modified Buckingham method is used (valid for 20° pressure angle). The tooth is checked against both dynamic load, surface wear and bending.

Total dynamic load per mm face width:
fd = Ft/b + ( Ft/b + A ) / ( 1 + 0.76·√(Ft/b + A) / v ) Ft = tangential load, b = face width, v = pitch-line velocity (m/s), A = factor for elastic modulus of the pair and the effective tooth error.
Permissible wear load (kgf/mm) = 2·K·ma·z₁·z₂ / (z₁ + z₂)
Permissible bending load (kgf/mm) = π·Sb·mn·Y Y = tooth form factor (depends on z). For corrected gears multiply by (Sf,corrected / Sf)². Allowable stresses Sb from Table 68; logarithmic coefficient L from Table 69 (used with Figs 56/57).
Face width:  b = Ft / f f = allowable tangential tooth load per mm width, from the chart at the gear's pitch-line velocity.
Factor of safety

Use a minimum factor of safety B = 1.25 in all cases; for shock loads such as in milling machines use B ≈ 2. The maximum dynamic load is divided by B to get the allowable load.

Helical gears p.275–291

Helical-tooth profile dimensions are based on the normal module mn (addendum, dedendum and the correction coefficients are taken in the normal plane). Centre distance and contact ratio are worked in the transverse plane using the transverse module mt.

Helical-gear relations (helix angle β)
QuantityFormula
Transverse modulemt = mn / cos β
Transverse pressure angletan αt = tan αn / cos β
Pitch circle diad = mn·z / cos β = mt·z
Centre distancea = mn·(z₁ + z₂) / (2·cos β)
Addendum / dedendumha = mn,  hf = 1.25·mn
Axial pitchpx = π·mn / sin β
Base tangent length over k teeth:
Wk = mn·cos αn·[ (k − 0.5)·π + z·inv αt ] + 2·mn·x·sin αn k = number of teeth spanned (from Fig 55, by z, β and correction x). inv α = tan α − α (involute function).

Tolerances for helical gears follow the same DIN class scheme as spur gears; strength uses the same Buckingham approach applied with the normal module mn and a virtual (formative) tooth number zv = z / cos³β for the form factor Y.
