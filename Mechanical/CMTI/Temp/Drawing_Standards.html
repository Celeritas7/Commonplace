Drawing sheet sizesp.83

The A-series (IS 696-1972) is built on two rules: halving — each size is half the area of the one above — and format similarity, the sides keeping the ratio Y = X·√2 so a sheet halved stays the same shape. A0 is exactly 1 m².

Orthographic projectionsp.84

In first-angle projection the object sits between observer and plane, so each view is pushed to the far side of the front view — top view below, left view to the right. In third-angle the plane is between observer and object, so views fall on the near side. The truncated-cone symbol in the title block declares which system is used.

Projection symbols — the truncated coneISO
The frustum's end view sits on opposite sides in the two systems — that is the whole convention.
Arrangement of views (directions A–F)
Same object, mirrored placement. A = front · B = top · C = left · D = right · E = bottom · F = rear.

Geometrical tolerancesp.101–102

The tolerance frame names a characteristic, a tolerance value and — for related features — a datum. Each characteristic defines a zone the feature must lie within.

How to read a tolerance frame
Form characteristics need no datum; attitude, location and runout always reference one.

Form characteristics — single features (no datum)
CharacteristicTolerance zone
StraightnessAxis or line lies between two parallel straight lines (or within a cylinder) apart by the tolerance.
FlatnessSurface lies between two parallel planes apart by the tolerance.
Circularity (roundness)Each cross-section lies between two concentric circles whose radial difference = tolerance.
CylindricitySurface lies between two coaxial cylinders whose radial difference = tolerance.
Profile of a lineProfile lies between two lines enveloping circles of dia = tolerance, centred on the true profile.
Profile of a surfaceSurface lies between two surfaces enveloping spheres of dia = tolerance, centred on the true surface.
