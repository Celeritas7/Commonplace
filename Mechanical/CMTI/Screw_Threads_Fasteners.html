ISO metric thread profile p.103–105

The ISO metric thread (IS 4218) has a 60° included angle. All proportions derive from the pitch p; the fundamental triangle height is H = 0.86603·p.

d2 = d − 0.64952·p    d1 = d − 1.08253·p    h3 = 0.61343·p d = nominal (major) dia, d2 = pitch dia, d1 = basic minor dia, h3 = bolt thread depth. Root of the external thread is rounded, r ≈ 0.14434·p.
Tensile stress area:  As = (π/4)·[ (d2 + d3) / 2 ]² d3 = d1 − H/6. Used with the property-class stresses below.

Thread engagement

Minimum useful engagement into a tapped hole: 1·d in steel, 1.25–1.5·d in cast iron, 2–2.5·d in aluminium alloys. Deeper engagement adds little — the first threads carry most of the load.

Locking against vibration, in rising order of security:

  • Spring (helical) washer — general machine work; loses effect after repeated re-use.
  • Lock nut / jam nut — thin nut run down against the main nut.
  • Tab washer — positive lock, bent against a flat; single use.
  • Castle nut + split pin — positive, for rotating or safety-critical parts.
  • Nylon-insert nut, thread adhesive — modern equivalents; note temperature limits.
