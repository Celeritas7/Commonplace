Harness Drawing Check-List

CAPSTONE — SYNTHESISED FROM §01–§06 SOURCE BINDERS

Everything the notebook covers converges on one artifact: the harness drawing. Before it releases, walk the circuits through this list — each line traces back to a sheet in the notebook if you need the reasoning.

THE CHECK-LIST
AreaCheckSheet
Wire specEvery wire has gauge, type (TXL/GXL/SXL…), colour and circuit number; drop ≤ 5% at the load; governing spec (SAE/JASO) named§02·05 ·06
RoutingClamp spacing & loom called out; bend radii honoured; splice locations marked, none in flex zones; drip loops on exposed drops§01·01 ·02
TerminationsTerminal family & part number per wire size; stud sizes match hole sizes; crimp tooling named on the drawing§03·04 ·06
ConnectorsKeying positions assigned so neighbours differ; IP class stated for exposed positions; contacts within current rating; pinout wired point-to-point§04·04
ProtectionEvery conductor fused upstream; device ≤ 125% of ampacity; placement distances honoured (72” main / 7”–40” branch); ratings on the drawing§05·02
SuppressionEvery coil shows its suppressor; signal runs separated from power; shields grounded per the diagram§05·03 ·04
MarkingOne colour per circuit end-to-end; conductor numbers at every termination match the diagram; test points shown; colour convention (automotive/AC/cabinet) declared§06·02
SymbolsIndicator symbols from the ISO basic set with registration numbers; no invented glyphs§06·01
✓ THE RELEASE TEST
A stranger with only the drawing, the wire tables and the crimp tools can build the harness, and an inspector with only the drawing can accept it to IPC-A-620 Class 2. If either needs to ask you something, the drawing is incomplete.
✗ THE USUAL GAPS
Crimp tooling left unnamed · keying letters “to be decided at assembly” · fuse ratings inherited from “same as last truck” · splice positions left to the builder — each one is a field failure with a date not yet filled in.
